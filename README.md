# Godot Utils

A collection of highly reusable and decoupled components for Godot 4.

## Modules Included

- **State Machine**: A clean, node-based state machine for entities. (`state_machine/`)
- **Random**: A global, seedable random number generator wrapper around PCG32. (`random/`)
- **Debug**: An extensible debug input controller for time-scaling and cheats. (`debug/`)
- **Camera**: A robust, trauma-based 2D camera shake implementation. (`camera/`)
- **Editor**: A custom Godot Editor dock for tracking project time and quick-switching scenes. (`editor/`)

## Examples

Check the `examples/` directory for copy-paste templates of how to implement each module.
