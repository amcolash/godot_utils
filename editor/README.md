# Editor Tools

Contains custom editor docks and viewport utilities for Godot.

## Tools Included

- **Array & Distribute Tool (`array_tool/`)**: 3D and 2D viewport toolbar tool for cloning node hierarchies and spacing/distributing selections with real-time bounding box previews and undo/redo support.
- **Scene Switcher (`default_scene.gd`)**: Quick scene switching dock.
- **Project Timer (`timer.gd`)**: Tracks active project time in the editor.
- **Editor Scale (`scale_button.gd`)**: Quick scale toggling utility.

## Usage
Enabled automatically when you activate the `Godot Utils` plugin from Project Settings -> Plugins.
